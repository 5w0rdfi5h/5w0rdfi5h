## Projects

**[Torpedo](https://github.com/5w0rdfi5h/Torpedo)** — C# red team utility for lateral movement over SMB/SCCM. Reimagines PsExec with token manipulation (PID steal or credential-based), fileless payload delivery over named pipes, runtime payload encryption, and clean artifact removal. Built for authorized red team engagements.

**CaroKann V2** *(private)* — Cross-process shellcode injection framework targeting CrowdStrike Falcon-protected endpoints. C# loader, C++ PIC shellcode (Fisher), MASM trampoline. Named after the chess opening that plays for controlled complications.

**Nimzo** *(private)* — Custom Mythic C2 agent rewritten in Rust (`no_std`, position-independent). Small footprint, controlled execution semantics, built for operational security. Named after Nimzowitsch — unconventional and deeply uncomfortable for defenders to face.
